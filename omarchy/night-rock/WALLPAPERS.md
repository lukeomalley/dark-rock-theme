# Wallpaper sources

The bundled paintings are high-resolution public-domain images downloaded
from the institutions listed below. The filenames in this theme correspond to
the source entries.

| File | Work | Artist | Source and rights |
| --- | --- | --- | --- |
| `01-entrance-to-a-village.jpg` | *Entrance to a Village* (ca. 1665) | Meyndert Hobbema | [The Metropolitan Museum of Art](https://www.metmuseum.org/art/collection/search/436652), Open Access/Public Domain |
| `02-woodland-road.jpg` | *Woodland Road* (ca. 1670) | Meyndert Hobbema | [The Metropolitan Museum of Art](https://www.metmuseum.org/art/collection/search/436653), Open Access/Public Domain |
| `03-wheat-fields.jpg` | *Wheat Fields* (ca. 1670) | Jacob van Ruisdael | [The Metropolitan Museum of Art](https://www.metmuseum.org/art/collection/search/437549), Open Access/Public Domain |
| `04-pastoral-landscape.jpg` | *Pastoral Landscape* (1861) | Asher Brown Durand | [National Gallery of Art](https://www.nga.gov/artworks/72881-pastoral-landscape), Open Access/Public Domain |

The original artwork and source images are in the public domain. This file is
included so downstream users retain useful title, creator, and source credits.
